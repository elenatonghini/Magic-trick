# Three bounded student tasks

1. **Reimplement reconstruction.** Prerequisites: arrays, objects, booleans, functions and addition. Write your own `inferNumber` using a loop rather than `reduce`. Explain why weights travel with answers. Verify with `npm test`, including 0, 42, 63 and reordered answers. Record what you wrote and what help you used.

2. **Build a binary switch.** Prerequisites: React props/state, event handlers, binary place value and semantic buttons. Rebuild one switch in an isolated component, then connect all six. Verify that toggling 32, 8 and 2 produces 42 / 101010, that Space and Enter work, and that screen readers announce its checked state. Keep bit order consistent.

3. **Improve scanning from real feedback.** Prerequisites: CSS Grid, responsive breakpoints and basic usability observation. Ask two classmates to find numbers on mobile without coaching. Record observed problems and actual comments with consent. Make one focused spacing or typography change. Repeat the task and compare observed errors or hesitation; do not invent results. Verify 360px overflow and keyboard focus after the change.
